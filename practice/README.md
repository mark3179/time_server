# Python 基础练习（结合当前项目）

你可以按顺序练习：

1. `python practice/01_collections.py`
- list/dict/set/tuple 的常见操作
- 经典写法和简化写法对比

2. `python practice/02_loops_and_conditions.py`
- if/for/range/enumerate
- 列表推导式和经典 append 对比

3. `python practice/03_functions_and_errors.py`
- 函数、类型转换、默认参数
- try/except 异常处理

4. `python practice/04_qa_data_practice.py`
- 贴近你当前 QA 项目的数据处理
- 最新记录查找、分组计数、去重保留最新

建议练习方式：
- 先运行看输出
- 再改数据、改条件
- 最后尝试自己写一个新函数并打印结果
